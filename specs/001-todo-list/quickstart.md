# Quickstart Guide: 001-todo-list

This is the development Quickstart corresponding to the 001-todo-list feature.

1. Ensure the Next.js baseline is initialized. Run `npm install` after ensuring your package.json reflects the Constitution's required dependencies (Next.js 15, Tailwind, Lucide React).
2. Start the application locally using standard commands (`npm run dev`).
3. View the application at `http://localhost:3000`. The theme should be dark by default.
4. Interact with the application:
   - Type in the input field to create a new task.
   - Click the completion checkbox to toggle statuses.
   - Click the delete icon to remove the task.
   - Switch between 'All', 'Active', and 'Completed' list views using the provided filters.
5. Hit `Cmd+R` or reload the browser. Confirm that the items populated persist exactly as they were prior to reload.
